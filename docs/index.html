Image Processing and Analysis in R

Professional repository showcasing image processing workflows in R using magick and imager.

Project focus

This project demonstrates how to build a maintainable image analysis pipeline in R, including grayscale conversion, edge detection, image transformation, segmentation, denoising, and morphology operations.

Repository structure

  • image_analysis.R — main analysis script
  • images/original/ — baseline input images
  • images/noisy/ — noisy images for denoising experiments
  • outputs/ — generated results organized by analysis type
  • docs/ — GitHub Pages landing page

Getting started

  1. Open image_analysis.R in R or RStudio.
  2. Place baseline images in images/original/.
  3. Run the script to generate output images.
  4. Inspect results in the outputs/ subfolders.
